# Charity Journey Map - Do-Nation Platform

## Journey Overview
Charities on Do-Nation receive two streams of support: direct periodic donations from users discovering them through AI matching or GlobalGiving search, and frequent micro matched donations from users whose giving is amplified by businesses.

## 🎯 Charity Goals
- Attract direct donations through AI discovery and project listings
- Benefit from high-frequency micro matched donations
- Build relationships with both individual donors and business partners
- Understand donor behavior through score-based insights

### 2. **Onboarding & Verification**

**ACNC Linking Process:**
```
Search ACNC Database → Select Charity → Upload Evidence 
→ Submit for Review → Await Approval (24-48hrs)
```

**Required Evidence:**
- Board resolution
- Authorized signatory letter
- Recent ACIS statement

**Dashboard Access Levels:**
- **Pre-verification**: Limited profile, no donations
- **Post-verification**: Full features + public profile

**Public Profile Creation:**
- Auto-generated at do-nation.com/charity/[name]
- Import ACNC data and ratings
- Add GiveWell/CharityNavigator ratings
- Upload impact photos/videos
- Write mission statement
- Display real-time donation counter

**Profile Features:**
- **Verification Badge**: ACNC approved
- **External Ratings**: Display third-party scores
- **Impact Metrics**: Lives helped, meals provided
- **Donor Wall**: Recent supporters (optional)
- **Business Partners**: Matching companies
- **Transparency**: Financial breakdowns

**Support Touchpoints:**
- Profile optimization guide
- SEO best practices
- Impact storytelling workshop
- Photography resources

**Emotions:**
- 🔒 Proud of verification
- 📈 Excited about discoverability
- 🌟 Confident with ratings display

### 3. **Payment Integration**

**Stripe Connect Setup:**
1. Create Stripe account
2. Business verification
3. Bank account connection
4. Tax information
5. Test transaction

**Benefits Realized:**
- Instant payment processing
- Lower transaction fees (2.2%)
- Direct bank deposits

**First Donations - Two Types:**

**Type 1: Direct Donation** ($50-$500)
- Notification: "New donor discovered you!"
- Often from AI matching or GlobalGiving
- Larger, periodic amounts
- Opportunity for deep engagement

**Type 2: Micro Matched** ($2-$50)
- Stream of small donations
- "Sarah donated $5, BusinessX matched $10!"
- High frequency (multiple daily)
- Builds sustainable base

## 🔄 Micro Matching Dynamics

### **Charity Perspective on Matching**

**Traditional Model:**
```
Find Donors → Ask for Money → Donor Fatigue 
→ High Acquisition Cost → Unsustainable
```

**Do-Nation Dual Stream:**
```
Stream 1: AI/Search Discovery → Direct Periodic Gifts → Deep Impact
Stream 2: Micro Matches → Daily Small Gifts → Sustained Revenue
Combined: Stable Base + Growth Potential
```

### **Public Discovery & Trust Building**

**Searchable Profile Elements:**
- Cause categories and keywords
- Geographic service areas
- Impact metrics (meals, lives, etc.)
- Minimum donation amounts
- Current urgent needs

**Trust Amplifiers:**
- **Import External Ratings**: 
  - ACNC registration status
  - CharityNavigator score
  - GiveWell recommendations
  - Local certifications
- **Display Do-Nation Metrics**:
  - Total raised on platform
  - Number of donors
  - Business match partners
  - Donor satisfaction score

**Competitive Advantages:**
- Higher search ranking with complete profiles
- Featured in category pages
- Recommended to aligned users
- Matched with businesses automatically

---

### **Managing Two Revenue Streams**

1. **Direct Donation Optimization**
   - Improve GlobalGiving listings
   - Optimize for AI matching
   - Create compelling project pages
   - Target $50-$500 gifts
   - Monthly/quarterly focus

2. **Micro Match Maximization**
   - Partner with multiple businesses
   - Encourage daily small gifts
   - Celebrate streaks and frequency
   - Target $2-$50 range
   - Daily/weekly engagement

3. **Unified Donor Journey**
   - Some donors do both
   - Track via unified scoring
   - Different comms for each type
   - Maximize lifetime value

4. **Business Relationships**
   - Not campaigns but partnerships
   - Ongoing micro matching
   - Shared donor base
   - Long-term alignment

## 🚀 The Transformation

Do-Nation transforms charity fundraising through public profiles and dual revenue streams:

**Public Profile Power**:
- **Searchable directory** of verified charities
- **Trust through transparency** with ratings display
- **Social proof** via donor counts and testimonials
- **SEO benefits** from do-nation.com domain
- **Viral discovery** through user/business profiles

**Stream 1 - Direct Discovery** (Periodic):
- Users find via search or AI matching
- Larger gifts ($50-$500)
- Driven by compelling profiles
- Monthly/quarterly frequency

**Stream 2 - Micro Matching** (Frequent):
- Daily $2-$50 gifts with matches
- Discovered through business partnerships
- High-frequency sustainability
- Predictable daily revenue

**The Platform Effect**:
- **Network growth**: Each user/business profile drives charity discovery
- **Trust cascade**: Verified profiles increase donation confidence

- **Zero CAC**: Platform brings donors to charities
- **Sustainable growth**: Public profiles + dual revenue streams
